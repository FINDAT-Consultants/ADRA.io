ASSURANCE REGENT / ADRA.io — RECOVERY AGENT v5.7.0
VOICE, LOCATION, RESEARCH & LOCAL-SERVICE UPGRADE

WHAT CHANGED
1. Microphone transcripts are submitted directly to Recovery Agent.
   - The transcript is NOT placed into the main Recovery Agent text field.
   - The transcript is NOT placed into the floating operator text field.
   - Manual Stop and automatic silence detection both submit the captured command.

2. Stop Speaking control.
   - A new square Stop button sits between Clear and the sound/mute button in the floating operator.
   - It immediately cancels browser SpeechSynthesis and the OpenAI audio fallback.
   - The written AI answer remains on screen.

3. Location-aware assistance.
   - If the browser has ALREADY granted geolocation permission, Recovery Agent can refresh coarse device coordinates without a new prompt.
   - If device location has not been granted, the Agent falls back to the signed-in employee/work location stored in Assurance Regent when available.
   - The Agent must identify a work-profile location as an approximation, not as exact current device location.

4. Public web research.
   - Recovery Agent can use public web search for current external information.
   - It can research public company/person contact details, nearby services, employment information and other public facts.
   - Private HR/payroll/banking/document content must not be placed into public search queries.

5. Research outputs.
   - Recovery Agent can create downloadable SVG visualizations from verified numeric research data.
   - Recovery Agent can create Word, PDF or TXT research documents.

6. Nearby food assistance.
   - Recovery Agent can research nearby food options using device location when already allowed, or the stored work location fallback.
   - It may only prepare an order handoff when the signed-in user explicitly asks it to order/buy/deliver food.
   - A browser confirmation is required before opening the external merchant ordering page.
   - This generic build does NOT contain merchant payment credentials or a universal food-delivery checkout API. Final payment/checkout remains with the merchant unless a dedicated trusted merchant integration is added later.

IMPORTANT BROWSER PERMISSION LIMIT
A normal website cannot programmatically bypass Chrome/Edge/Firefox/UC Browser microphone or geolocation permission. The first getUserMedia/geolocation access is controlled by the browser.

The screenshot showing:
  C:/Users/.../index.html
is a local file (file://) preview. Browsers treat local files differently and may prompt again.

For the normal deployed Assurance Regent site:
  - deploy through HTTPS (Netlify)
  - grant Microphone = Allow once in browser site settings
  - after that, supported browsers normally allow subsequent recordings without another prompt unless permission/site data is reset

Assurance Regent itself does not display an extra custom microphone permission popup.

DEPLOYMENT
1. Replace the GitHub/Netlify project with the contents of ADRA.io-main-v5.7.0-complete.zip.
2. Deploy the included RECOVERY_AGENT_EDGE_FUNCTION.ts to Supabase Edge Functions -> recovery-agent.
3. Keep OPENAI_API_KEY in Supabase Edge Function Secrets.
4. No new database SQL migration is required if Developer Governance v5.4.0 was already installed.
5. Test on the deployed HTTPS site rather than opening index.html directly from a local C: drive.

TESTS
A. Microphone direct submit
   - Click Mic.
   - Speak: "Open Payroll and wait for me."
   - Click Stop, or pause until automatic stop.
   - The transcript should appear as a user message and be processed immediately; the text entry box should remain empty.

B. Stop speaking
   - Ask Recovery Agent for a long spoken answer.
   - While it is speaking, press the square Stop button between Clear and the speaker icon.
   - Audio should stop immediately; the text response remains visible.

C. Location-aware research
   - With location already granted, ask: "Find restaurants near my current location."
   - Without location permission, the Agent should use a stored work location if one exists or ask for a city/area.

D. Research artifact
   - Ask: "Research the latest public employment numbers for my area and make a simple visualization."
   - Or: "Create a PDF research summary."

E. Food order handoff
   - Ask: "Find nearby lunch options."
   - Then explicitly: "Order from [selected restaurant]."
   - Recovery Agent should ask for/require confirmation before opening the merchant ordering page.
