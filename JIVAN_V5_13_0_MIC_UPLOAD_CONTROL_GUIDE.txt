ASSURANCE REGENT — JIVAN v5.13.0 MICROPHONE, MINIMIZE, CLEAR & UPLOAD GUIDE

1. MICROPHONE PERMISSION
- Assurance Regent records an application-side marker after microphone access succeeds.
- On later visits, Jivan checks the browser Permissions API. If the browser reports microphone=granted, Jivan primes the microphone without issuing another application permission request.
- If Voice conversation was left enabled, Jivan resumes it automatically only when the browser already reports permission as granted. It never auto-prompts from a prompt/unknown state.
- Browser permission persistence itself is controlled by the browser/site permission choice. Choose the browser option that allows microphone access on future visits (for example Chrome's ongoing Allow option), not a one-time option.

2. VOICE CONVERSATION
- One manual Voice conversation start remembers the preference.
- When permission remains granted, later Assurance Regent sessions can resume the continuous VAD conversation automatically.
- Explicitly pressing End voice disables the remembered auto-resume preference.

3. MINIMIZE / CLOSE
Commands such as "Jivan minimize", "close Jivan", or "hide the agent" minimize the Jivan interface immediately.
A Minimize control also exists in the full Jivan page and floating header.
Voice conversation may continue while the visual panel is minimized.

4. CLEAR / NEW CHAT
Commands such as "Jivan clear the conversation" and "start a fresh chat" clear the Supabase Jivan thread, main chat, floating chat, pending approvals, last-document context and compose fields, then display a fresh conversation state.
The Clear conversation button now follows the same fresh-chat behavior.

5. FILE PICKING / UPLOAD
Typed upload instructions are intercepted before the network AI round trip, while the user's click/Enter activation is still available. This makes the browser file chooser much more reliable.
Examples:
  - "Jivan upload a PDF from my computer"
  - "Choose July Payroll.xlsx and analyze it"
  - "Upload this document to the document inbox"
  - "Change my profile picture"
After the user selects the local file, Jivan automatically analyzes it, submits it to the document workflow, or saves the profile image as appropriate.
Voice-only upload commands also attempt the picker, but browsers may require a user click before opening a local-file chooser. Jivan therefore provides a one-click Choose file fallback in both the main chat and floating panel.

6. LOCAL FILE SECURITY BOUNDARY
A normal website cannot silently browse arbitrary computer folders or select a local file solely because it is visible on the operating-system screen. The user must grant the file to the website through the OS/browser picker. Once granted, Jivan continues automatically. Documents already stored inside Assurance Regent can be analyzed without another local picker.
