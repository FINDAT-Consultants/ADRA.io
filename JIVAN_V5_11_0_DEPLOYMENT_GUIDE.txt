JIVAN v5.11.0 DEPLOYMENT GUIDE

PURPOSE
This release preserves Assurance Regent v5.10.0 and adds a consistent human voice plus wake-word activation for Jivan.

DEPLOYMENT
1. Replace the current GitHub/Netlify project with the contents of ADRA.io-main-v5.11.0-complete.zip.
2. Let Netlify finish deploying.
3. Hard refresh the deployed HTTPS Assurance Regent site.
4. No new Supabase SQL is required.
5. No Recovery Agent Edge Function replacement is required for this release.

VOICE TEST
1. Sign in.
2. Allow Jivan to greet you.
3. Ask a longer question such as: "Jivan, analyze the dashboard and explain what needs attention."
4. The greeting and the long analysis should use the same natural voice.
5. Ask Jivan to sign you out. The same voice is used for the farewell before sign-out.

WAKE-WORD TEST
1. Microphone permission must already be granted to the deployed Assurance Regent HTTPS site. If it has never been granted, click Mic once and allow the site.
2. Confirm the Jivan page shows Wake: listening (or the floating wake indicator is active).
3. Without clicking Mic, say: "Jivan".
4. Jivan should answer: "Yes. I'm listening." and automatically start command recording.
5. Speak your instruction and pause; it should submit automatically.
6. You may also say one phrase such as: "Jivan, open payroll." When browser speech recognition captures the whole phrase, it is sent directly.

PRIVACY / BROWSER BEHAVIOR
Wake mode never intentionally triggers a first-time microphone permission popup on page load. It starts automatically only when the site already has microphone permission (or permission was granted by using Mic previously). Wake listening pauses while Jivan speaks, during active recording, while the tab is hidden, and after sign-out.

Browser continuous SpeechRecognition support differs. Where the browser does not provide it, normal Mic push-to-talk continues to work.
