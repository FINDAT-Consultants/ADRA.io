Assurance Regent v4.4.5 — Netlify server bundle fix

Problem fixed
-------------
Netlify returned:
  Cannot find module '/var/task/server.js' imported from /var/task/netlify/functions/api.cjs

Cause
-----
The CommonJS function used dynamic import('../../server.js'). Dynamic imports are not a reliable bundle-discovery anchor for this project layout, so Netlify deployed api.cjs without the root server.js module.

Fix
---
1. The Netlify entry is now netlify/functions/api.js.
2. package.json already declares "type": "module", so Netlify executes api.js as an ES module.
3. api.js uses static imports for both serverless-http and ../../server.js. This lets esbuild follow and bundle the server.js -> src/* import graph.
4. Runtime JSON reference files under data/ are explicitly included through netlify.toml.
5. api.cjs and api.mjs must not remain in netlify/functions/.
