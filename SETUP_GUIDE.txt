Assurance Regent v5.4.0

EXISTING INSTALLATION
1. Run DEVELOPER_GOVERNANCE_V5_4_0.sql LAST in Supabase SQL Editor.
2. Run DEVELOPER_GOVERNANCE_V5_4_0_VERIFY.sql and confirm schemaVersion 5.4.0 / governanceReady true.
3. Deploy the website from this package.

NEW DATABASE
1. Run ASSURANCE_REGENT_SUPABASE_SETUP.sql.
2. Install/upgrade Recovery Agent SQL if required by your existing deployment path.
3. Run DEVELOPER_GOVERNANCE_V5_4_0.sql LAST if any older Recovery Agent SQL was run after the main setup.
4. Deploy RECOVERY_AGENT_EDGE_FUNCTION.ts if the Recovery Agent Edge Function is not already deployed.
5. Deploy the website from GitHub/Netlify.

See DEVELOPER_GOVERNANCE_V5_4_0_DEPLOYMENT_GUIDE.txt for the full test plan.
