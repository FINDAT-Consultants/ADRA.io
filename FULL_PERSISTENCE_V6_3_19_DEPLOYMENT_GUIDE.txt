- Original profile/employee/candidate/vacancy images: private Supabase Storage; compatible JPEG thumbnails remain in app state for display.

- Jivan document uploads: persisted to private Storage before optional AI analysis.

FILE POLICY
- Internal Storage accepts arbitrary MIME/file types up to 50 MB per object.
- Browser preview depends on browser codec support; unsupported image formats can still be stored as originals.
- Jivan direct document analysis remains limited to 5 MB per file because that file must be sent to the AI analysis service.
- Public recruitment uploads retain stricter safe-type restrictions intentionally; executable/active-content uploads are not enabled on the public careers surface.
