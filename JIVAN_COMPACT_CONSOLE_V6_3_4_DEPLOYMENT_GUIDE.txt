ASSURANCE REGENT v6.3.4 — COMPACT DEVELOPER JIVAN CONSOLE + CONTINUOUS SPEECH

PURPOSE
- Keep all v6.3.3 capabilities while making the Developer Jivan console fit normal laptop viewports without the page-level scrollbar.
- Make Jivan continue speaking through long responses instead of stopping after an early sentence/chunk.

UI CHANGES
- Developer console height is now viewport-aware and substantially smaller.
- Header controls, tabs, telemetry panels, hologram core, routing cards, chat bubbles, composer and Studio modules are compacted.
- On desktop/laptop Developer Jivan view, the outer page scrollbar is suppressed; conversation history remains independently scrollable inside Jivan when required.
- Ordinary non-Developer Jivan layouts are unchanged.

VOICE CHANGES
- Jivan now breaks long text into smaller stable speech chunks and continues through the complete response.
- Speech playback supports substantially longer replies than v6.3.3.
- A speech heartbeat resumes a browser speech engine if it enters a paused state.
- A transient error on one speech chunk is retried once and does not automatically discard the rest of the answer.
- The same locked human voice remains in use; this update does not switch to a robotic fallback voice.
- Stop Speaking, mute and continuous Voice Conversation behavior remain available.

DEPLOYMENT
1. Deploy the v6.3.4 complete ZIP to the normal GitHub/Netlify deployment, or overlay the v6.3.4 patch on v6.3.3.
2. Hard refresh the deployed HTTPS Assurance Regent site.
3. No Supabase SQL migration is required.
4. No recovery-agent Edge Function replacement is required for v6.3.4.

TEST
- Open Jivan as Developer on a laptop-sized screen. The entire console should fit in the visible workspace without the browser/page scrollbar at the far right.
- Check CONVERSE, ARCHITECT, AGENTS, COMMS, ENGINEERING and ACTIVITY. Their controls should be noticeably more compact.
- Ask Jivan for a response of several paragraphs and enable voice. Jivan should speak through the entire available response unless the user presses Stop Speaking or mutes voice.
- In Voice Conversation mode, after Jivan completes the full spoken response, the microphone should return to listening for the next user turn.
