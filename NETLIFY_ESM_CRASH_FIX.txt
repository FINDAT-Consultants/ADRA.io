ASSURANCE REGENT v4.4.3 — NETLIFY ESM/COMMONJS FUNCTION FIX

Problem fixed:
Netlify reported:
  Error [ERR_REQUIRE_ESM]: require() of ES Module .../netlify/functions/api.mjs
  from .../api.js not supported.

Cause:
The application is an ES-module project (package.json contains "type": "module"),
but Netlify's Lambda-compatible wrapper attempted to load the .mjs function through
CommonJS require().

Fix in v4.4.3:
1. Deleted: netlify/functions/api.mjs
2. Added:   netlify/functions/api.cjs
3. api.cjs is a CommonJS Netlify entry point and uses dynamic import() to load the
   ESM Assurance Regent server and serverless-http.
4. package.json validation now checks api.cjs.
