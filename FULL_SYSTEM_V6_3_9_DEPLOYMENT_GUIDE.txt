FRESH SUPABASE DEPLOYMENT
-------------------------
1. Create/open the target Supabase project.
2. Open SQL Editor.
3. Run ASSURANCE_REGENT_SUPABASE_SETUP_V6_3_9.sql once.
4. Run ASSURANCE_REGENT_SUPABASE_VERIFY_V6_3_9.sql and confirm required objects report true.
5. Deploy both Edge Functions:
     supabase functions deploy recovery-agent
     supabase functions deploy voice-access
6. Configure any optional provider secrets used by Jivan integrations (OpenAI, Resend, Twilio) only
   in Supabase Edge Function Secrets. Never put service-role secrets in browser JavaScript.
7. Deploy the /public directory to Netlify or your configured static host.

UPGRADING AN EXISTING v6.3.8 DATABASE
-------------------------------------
If the v6.3.8 database is already installed and healthy, run only:
  JIVAN_VOICE_ACCESS_V6_3_9.sql
Then deploy/update both Edge Functions and deploy the current /public build.

VOICE ACCESS
------------
Registration supports private three-sample voice enrollment.
Sign-in provides Jivan Instruction and Recognize Voice modes.
Voice recognition uses a dynamic spoken challenge plus an enrolled speaker template.
Normal password sign-in remains available.

DEVELOPER JIVAN
---------------
The sidebar Jivan developer engine is developer-only.

The removed hologram/conversation controls are not part of the developer engine UI.
