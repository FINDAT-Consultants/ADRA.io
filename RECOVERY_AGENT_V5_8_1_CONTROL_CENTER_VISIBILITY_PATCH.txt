Assurance Regent v5.8.1 — Control Center / Recovery Operator visibility patch

Changes
- Recovery AI Operator is hidden whenever Control Center -> Profile is open.
- Recovery AI Operator is hidden whenever Control Center -> Settings is open.
- Recovery AI Operator is hidden whenever Control Center -> Reviews is open.
- Recovery AI Operator is hidden whenever Control Center -> Notifications is open.
- The floating operator panel is also force-closed if it was already open when one of these Control Center panes opens.
- When the Control Center drawer closes, the Recovery AI Operator returns on eligible pages.
- The dedicated Recovery Agent page behavior is unchanged: the floating operator remains hidden there.
- Documents remains unchanged because it was not requested as a blocking Control Center pane.

Deployment
No new Supabase SQL or Edge Function deployment is required for this UI-only patch. Deploy the updated project to GitHub/Netlify and hard-refresh the browser after deployment.
