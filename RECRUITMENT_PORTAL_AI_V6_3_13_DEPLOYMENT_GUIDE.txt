ASSURANCE REGENT v6.3.13 — BRANDED RECRUITMENT, AI FIT REVIEW & OUTREACH

EXISTING v6.3.12 DATABASE
1. Open Supabase SQL Editor.
2. Run RECRUITMENT_PORTAL_AI_V6_3_13.sql.
3. Run RECRUITMENT_PORTAL_AI_V6_3_13_VERIFY.sql.
4. Redeploy supabase/functions/recruitment-public/index.ts.
5. Deploy the complete /public folder from this release.
6. Hard refresh the private Assurance Regent browser tab.

NEW / FRESH SUPABASE PROJECT
1. Run ASSURANCE_REGENT_SUPABASE_SETUP_V6_3_13.sql.
2. Run ASSURANCE_REGENT_SUPABASE_VERIFY_V6_3_13.sql.
3. Deploy all Edge Functions in supabase/functions/.
4. Deploy /public.

REQUIRED RECRUITMENT EDGE FUNCTION SECRETS
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY

AI FIT REVIEW / AI MESSAGE DRAFTING
- OPENAI_API_KEY
- OPENAI_MODEL (optional; defaults to the model configured in the function)
AI analysis is advisory only. It uses job-related application data and does not automatically change an applicant's shortlist/reject status. HR reviews the evidence and makes the employment decision.

DIRECT EMAIL DELIVERY (OPTIONAL)
- RESEND_API_KEY
- RECRUITMENT_FROM_EMAIL
If these are not configured, the Send email button opens the user's prepared mail client with applicant email, subject and message pre-populated.

DIRECT WHATSAPP CLOUD DELIVERY (OPTIONAL)
- WHATSAPP_ACCESS_TOKEN
- WHATSAPP_PHONE_NUMBER_ID
- WHATSAPP_GRAPH_VERSION (for example the Graph API version currently enabled for your Meta app)
If these are not configured, Assurance Regent opens a pre-filled WhatsApp conversation using the applicant's submitted phone/WhatsApp number.

PUBLIC SURFACES
- /careers.html (or /careers through the included redirects) — isolated applicant careers portal.
- /interview.html?token=... — isolated candidate interview invitation.
Neither page loads the private Assurance Regent app shell, sidebar, Zari/Jivan operator, sign-in page, employee directory or internal application controls.

VACANCY DEADLINES
- Public list requests reject/hide expired jobs immediately.
- HR client archives expired jobs when Recruiting is opened.
- The SQL migration also adds an expiry function and best-effort daily pg_cron scheduling when pg_cron is available.
- Archived vacancies disappear from active/public lists but remain in HR's Past vacancies section so history can be audited and the vacancy record can be manually deleted.
- Existing applicant/interview history is preserved when a vacancy record is removed from the live vacancy list.

ATTACHMENTS
- CV: PDF/DOC/DOCX, max 6 MB.
- Additional recruitment files: up to 4 files, max 5 MB each, max 8 MB combined.
- Executable and script formats are intentionally blocked even though ordinary recruitment document/image/spreadsheet/presentation/archive formats are accepted.
- Storage bucket remains private; HR receives short-lived signed document URLs.
