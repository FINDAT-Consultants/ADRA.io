Traffic architecture

What v6.1 protects

Request poolingBrowser traffic is capped and queued instead of creating unbounded simultaneous requests.
Read coalescingIdentical health/context reads share in-flight requests and short-lived cache entries.
Write coalescingRapid operational changes collapse into the newest state snapshot instead of building a long save backlog.
Backoff & timeoutSafe reads retry transient failures with bounded backoff; long calls time out instead of hanging indefinitely.
Database indexesSession, Jivan queue, leave and recovery assurance hot paths receive dedicated indexes.
Rate limitingHigh-cost Jivan requests use per-user server-side buckets to protect shared capacity.
