Assurance Regent Recovery Agent v5.2.1 — Profile/Logout UI Patch

What changed
------------
1. Recovery AI Operator is hidden whenever Control Center > Profile is open.
2. If the floating operator panel was open, opening Profile closes/hides it immediately.
3. Closing the Profile drawer restores the floating Recovery launcher on eligible pages.
4. Profile Save/Sign Out actions are sticky at the bottom of the Profile panel so they remain reachable while scrolling.
5. Sign Out is now a vivid solid red action with clear hover/focus states.
6. On small screens, Save Profile and Sign Out stack full-width for easier use.

Deployment
----------
No Supabase SQL or Edge Function change is required for this patch.
Replace the GitHub site files with the v5.2.1 package (or copy app.js, recovery-agent-v5.js, styles.css and index.html from the patch) and let Netlify redeploy.
After deployment, hard refresh the browser.

Test
----
- Open Dashboard. Recovery launcher may be visible.
- Click Control Center > Profile. Recovery launcher/panel must disappear.
- Scroll the Profile panel. Save Profile and Sign Out must remain clearly accessible.
- Close Profile. Recovery launcher should return on the current eligible page.
