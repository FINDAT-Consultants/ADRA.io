JIVAN v5.13.0 DEPLOYMENT

No new Supabase SQL migration is required.
No Recovery Agent Edge Function change is required for this release; the existing request_file_upload tool remains compatible.

Deploy the complete package through the normal GitHub/Netlify workflow. Netlify publishes the /public directory.
After deployment, hard refresh once.

Test:
1. Open the deployed HTTPS Assurance Regent site.
2. Grant microphone using the browser's ongoing site permission, not a one-time grant.
3. Start Voice conversation once, speak, and verify Jivan answers and returns to listening.
4. Reload/reopen Assurance Regent. If the browser reports microphone permission as granted and Voice conversation was not explicitly ended, Jivan should resume without another Jivan-generated permission request.
5. Type "Jivan minimize" and verify the floating panel closes (or the full Jivan page returns to Dashboard).
6. Type "Jivan clear the conversation and start fresh" and verify both chat surfaces reset.
7. Click Send with "Jivan upload a PDF from my computer" and verify the chooser opens immediately. Select a file and verify automatic analysis.
8. In Control Center Documents, instruct Jivan to upload a document; select it and verify automatic submission to Pending Review.
